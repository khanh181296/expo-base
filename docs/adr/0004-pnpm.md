# 0004. pnpm với isolated node_modules

**Trạng thái:** Chấp nhận

**Bối cảnh:** Cài đặt kiểu hoisted (npm, yarn) cho phép import nhầm thư viện không khai báo, gây lỗi khó tìm khi nâng cấp.

**Quyết định:** pnpm 10, giữ isolated mặc định (Expo hỗ trợ từ SDK 54). Thư viện nào bị import từ code app phải nằm trong `package.json` (ví dụ `react-native-css-interop`).

**Hệ quả:** Phụ thuộc rõ ràng, cài nhanh. Nếu một thư viện native lỗi với isolated, có thể đặt `nodeLinker: hoisted` trong `pnpm-workspace.yaml` và ghi ADR mới.
